# Context Documentation - gzh-cli-core

This directory contains detailed context documentation extracted from CLAUDE.md for LLM optimization.

## Purpose

Keep CLAUDE.md concise while maintaining comprehensive guidance through linked context documents.

## Files

| File | Purpose | When to Read |
|------|---------|-------------|
| [common-tasks.md](common-tasks.md) | Using config, logger, errors, cli, testutil, version packages | Daily development |
| [architecture-guide.md](architecture-guide.md) | Package map, dependency direction, design principles | New to the project or adding packages |

## Quick Access

**New to the project?** Read in order:

1. CLAUDE.md (quick overview)
2. architecture-guide.md (understand package structure)
3. common-tasks.md (how to use each package)

**Adding a new utility?**
- Check architecture-guide.md for package conventions
- Follow common-tasks.md "Adding a New Utility Package" pattern
